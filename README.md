# منصة التقنية والأناقة — بوابتك إلى الاحتراف الرقمي

موقع ثابت باللغة العربية، متجاوب مع الجوال والكمبيوتر، يحتوي على:

- مختبر تمارين HTML وCSS وJavaScript بمحرر CodeMirror (ومحرر بديل عند عدم توفر الشبكة).
- معاينة داخل iframe مقيّد باستخدام sandbox وContent Security Policy.
- فحص تلقائي لمعايير التمارين، وحفظ التقدم في LocalStorage.
- منشئ أوامر للصور وقوالب أوامر جاهزة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وليكن `tech-elegance-platform` واختر **Public**.
2. ارفع محتويات هذا المجلد إلى **جذر المستودع**، بما فيها `index.html` و`.nojekyll`. لا ترفع مجلدًا يحتوي هذه الملفات داخل مجلد آخر.
3. من صفحة المستودع افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر `main` و`/(root)` ثم **Save**.
6. بعد اكتمال النشر يظهر الموقع عادة على:
   `https://USERNAME.github.io/tech-elegance-platform/`
   مع استبدال `USERNAME` باسم مستخدم GitHub الفعلي.

> إذا استخدمت مستودعًا باسم `USERNAME.github.io`، سيكون الرابط `https://USERNAME.github.io/`.

## التشغيل المحلي

افتح `index.html` في المتصفح مباشرة. لا تحتاج خادمًا أو تثبيت حزم.

## ملاحظات مهمة

- المكتبة والخطوط تُحمّل من خدمات CDN؛ يلزم الإنترنت للاستفادة من CodeMirror وخط Tajawal، مع وجود محرر بديل عند فشل تحميل CodeMirror.
- الحفظ محلي في المتصفح والجهاز نفسه، وليس على حساب GitHub أو قاعدة بيانات.
- اختبارات التمارين تفحص عناصر وشروطًا محددة، ولا تضمن سلامة كل كود يكتبه المستخدم.
- المعاينة معزولة باستخدام iframe sandbox وسياسة CSP داخل المستند؛ هذا تقييد دفاعي وليس ضمانًا أمنيًا مطلقًا ضد كل تهديد.
- أداة الأوامر تصوغ النصوص ومعاينة تصورية، ولا تتصل بخدمة توليد صور فعلية.
- غيّر روابط `example.com` والبريد التجريبي داخل أمثلة التمارين إذا أردت تخصيصها.

## التخصيص

الألوان والخطوط موجودة في `<style>` داخل `index.html`. يمكنك تعديل متغيرات `:root` لضبط ألوان الهوية.
